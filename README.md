# Segmentación de Jurisdicciones Argentinas por Viviendas Habitadas

Trabajo práctico de Ciencia de Datos enfocado en la aplicación del algoritmo de aprendizaje no supervisado **K-Means Clustering** sobre datos oficiales del INDEC (Censo 2022).

## Objetivo
Agrupar las 24 jurisdicciones de Argentina en tres segmentos homogéneos según su cantidad de viviendas particulares habitadas:
1. **Muchas viviendas**
2. **Cantidad normal de viviendas**
3. **Pocas viviendas**

## Estructura del Repositorio
- `segmentacion_viviendas.py`: Script principal en Python con la implementación del modelo y visualizaciones.
- `README.md`: Documentación detallada del proyecto.
- CONCLUSION.md: informe detallado y conclusion final.
